# OJEE Students Zone — Website

A responsive, animated coaching-institute website for OJEE Students Zone.

## Included
- Institute logo
- "JOIN THE CLASS. FEEL THE DIFFERENCE." hero
- Established 2020 branding
- Our Achievers gallery using the supplied artwork
- Full-screen image viewer with previous/next controls
- Scroll animations and animated background particles
- Call, WhatsApp and Gmail buttons
- Google Play and YouTube buttons ready for your real links
- Responsive mobile navigation
- No location section
